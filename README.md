## Problem Statement

Business leaders struggle with a set of challenges that grow harder, not easier, as organizations scale:

- **Opportunity blindness** — promising signals get lost in noise before anyone acts
- **Sentiment gaps** — leadership rarely has a live read on how customers actually feel
- **Competitive lag** — by the time competitor moves are noticed, the window has closed
- **Decision latency** — gathering context for a strategic call takes days, not minutes
- **Execution fragmentation** — strategy and operations rarely stay synchronized

The result: critical decisions are made using incomplete, stale, or misaligned information. Fortune.Guide closes that gap.

### Fortune Score™

A proprietary business intelligence metric that distills complex multi-dimensional data into a single executive-grade signal.

**Inputs:**

| Dimension | Signal |
|---|---|
| Customer Sentiment | NLP analysis of support interactions and feedback |
| Market Momentum | Trend velocity and competitor activity |
| Growth Indicators | Pipeline health and expansion signals |
| Competitive Pressure | Market share dynamics and threat proximity |
| Operational Performance | Internal efficiency and delivery metrics |

**Output:** A **0–100 Fortune Score** — a simple answer to the most difficult executive question:

> *"How healthy is my business right now?"*

### Guide Council™

A collaborative multi-agent intelligence system where specialized AI agents debate, analyze, and vote before producing any recommendation — delivering more reliable strategic guidance than any single model could provide alone.

#### Fortune Scout
Identifies trends, emerging opportunities, and early-stage threats by continuously scanning market signals, news, and competitive intelligence sources.

#### Guide Strategist
Synthesizes intelligence from all agents into concrete business recommendations, ranked by impact, feasibility, and strategic alignment.

#### Sync Orchestrator
Coordinates execution workflows across teams and systems, ensuring strategic decisions translate into coordinated action.

#### Audit Sage
Tracks prediction accuracy, recommendation outcomes, and organizational learning — closing the feedback loop between strategy and results.

> Agents reason independently before producing consensus recommendations, reducing hallucination risk and improving decision quality.

---

### Fortune Map™

An interactive opportunity visualization layer that converts business intelligence into a navigable strategic map.

- Visualize **opportunities** grouped by potential and effort
- Surface **threats** with proximity indicators before they become crises
- Detect **market shifts** as they form, not after they land
- Explore **strategic pathways** and understand the reasoning behind each recommendation

Fortune Map makes abstract intelligence tangible — executives can see where the organization stands and where it needs to go.

### Fortune Ledger™

A transparent decision history system that creates organizational memory and makes every AI recommendation auditable.

| Entry | What Is Captured |
|---|---|
| Recommendation | What the system advised and why |
| Prediction | What outcome was forecast |
| Action | What was actually executed |
| Outcome | What result was measured |

This produces **explainable AI** — leadership never has to trust a black box. Every recommendation has a traceable lineage from signal to suggestion to outcome.

## Getting Started

### Prerequisites

- Node.js 16+
- Python 3.10+
- OpenAI API key
- SerpAPI key

### Installation

```bash
# Clone the repository
git clone https://github.com/your-org/fortune-guide.git
cd fortune-guide

# Install frontend dependencies
npm install

# Install backend dependencies
cd backend
pip install -r requirements.txt
```

### Configuration

Create a `.env` file inside `backend/`:

```env
OPENAI_API_KEY=your_openai_key_here
SERPAPI_API_KEY=your_serpapi_key_here
EMAIL_SENDER=your_sender_email
EMAIL_PASSWORD=your_email_password
```

### Running the Platform

```bash
# Start the Fortune Dashboard (project root)
npm start

# Start the Guide Council API (backend/)
python app.py
```

The Fortune Dashboard opens at `http://localhost:3000`.  
The Guide Council API runs at `http://localhost:5000`.
